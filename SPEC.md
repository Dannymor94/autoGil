# SPEC.md — Daily Planner (M0)

## Принципы
- Determinism-first. В M0 LLM не используется вообще.
- Two-phase. M0 = только Фаза 1 (черновик на ревью). Записей в YouGile нет.
- Границы: планировщик трогает только статус/колонку (в M1+). Содержимое задач — зона «Созвон→Задачи». M0 не пишет ничего.

## Источник данных
- `get_user_tasks(me)` → все задачи через проекты одним вызовом.
- Фильтр по `projectId` в API НЕ поддерживается → группировка по boardId/projectId локально.

## Модель задачи (используемые поля)
- `id`, `title`, `projectId`, `boardId`, `columnId`
- `createdAt` (ms) — возраст
- `deadline` = `{ deadline: ms, startDate, withTime }` — близость срока
- `timeTracking.plan` (часы) — оценка (для M4)
- `completed` (bool)

## Колонки
- `final_columns: []` — настраиваемый список «Сделано/Архив» (по columnId).
- В планирование идут только: `completed == false` И `columnId ∉ final_columns`.

## Активный набор и пул (на проект)
- Активный набор = top-3 кандидатов проекта по детерминированному правилу: `deadline ASC` (нет дедлайна → в конец), затем `createdAt ASC` (старые выше).
- Пул = остальные кандидаты проекта.

## Срочность (детерминированная, TUNABLE)
- `age_score = clamp(days_since(createdAt) / AGE_CAP, 0, 1)`, `AGE_CAP = 30`.
- `deadline_score`: нет дедлайна → 0; иначе `clamp((HORIZON - days_to_deadline) / HORIZON, 0, 1)`, `HORIZON = 14`; просрочка → 1.
- `score = W_D * deadline_score + W_A * age_score`, дефолт `W_D = 0.7`, `W_A = 0.3`.
- Флаг `горит` = просрочен ИЛИ `days_to_deadline <= FLAME_DAYS (=3)` ИЛИ `age_score >= 0.8`.

## Селектор (8 слотов, контракт)
- Вход: активные наборы всех проектов + проект `Личные` (его задачи = блоки отдыха, конкурируют наравне).
- Выход: единый упорядоченный список ≤ 8 по убыванию `score`.
- 8 слотов = вся сумма дня (работа + отдых + созвоны).
- Re-run контракт (для M4, в M0 не задействован): вход `accepted[]` (зафиксированы), `rejected[]` (исключить из ТЕКУЩЕЙ пересборки); добор из остатка пула под свободные слоты. `rejected` НИКОГДА не убирается из учёта срочности — назавтра возвращается горячее.

## Вывод
- Печатный одностраничник (`plan-pdf`): 8 слотов, флаги `горит`, проект каждой задачи.
- Никаких записей в YouGile.

## Не-цели M0
- Перемещение карточек (M1), голос (M2), LLM-выбор (M3), декомпозиция и упаковка в часы (M4).
