# skills/plan-pdf/SKILL.md

## Purpose
Печатный одностраничник дневного плана (под бумагу + ручку).

## Содержимое
- До 8 слотов сверху вниз по score.
- Колонки строки: метка слота, флаг `🔥`, проект, заголовок задачи, дедлайн (если есть).
- Дата плана, час генерации.

## Рендер
- HTML → PDF через WeasyPrint.

## Грабли WeasyPrint (соблюдать)
- Разрыв страниц: `break-before: page` на контейнере секции. НЕ `break-inside: avoid` на элементах выше высоты страницы — падает на assertion.
- НЕ использовать `calc()` во `flex-basis` — ненадёжно, ставить фиксированные проценты.
- Variable-шрифты: пиннить обе оси для инстансинга.

## Rules
- A4, печать-френдли (моно-контраст, без фоновых заливок, поля под черкание).
- Вывод в выходную папку; имя с датой.
